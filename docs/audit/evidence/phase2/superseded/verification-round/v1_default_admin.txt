=== V1.1: WHY POST-FIX SMOKE TEST LOGGED IN AS admin@example.com ===
Explanation: docker-compose.phase2.yml attached persistent named volume 'phase2-pgdata'.
Prior to FIX-03, seed_data.py seeded admin@example.com into the volume on container initial startup.
seed_initial_data() skips seeding if an admin user already exists (select User where role='ADMIN').
Restarting containers without '-v' preserved the existing database volume rows.
smoke_test.py used admin@example.com / Admin123!Secure and authenticated against the pre-existing row.
Result: Verified root cause of persistent volume behavior.
