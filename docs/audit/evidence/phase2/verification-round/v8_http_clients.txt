================================================================================
=== V8: COMPREHENSIVE PYTHON HTTP CLIENT AUDIT ===
================================================================================
Audit Scope: All non-test Python files in the repository.
Libraries audited: httpx, aiohttp, requests, urllib / urllib.request.

SUMMARY FINDINGS:
1. `aiohttp`, `requests`, and `urllib.request` are NOT imported or used anywhere in production or service code.
2. `httpx` is the single unified HTTP client library used across the entire backend.
3. Outbound pentesting HTTP requests are strictly routed through either:
   (a) `safe_request()` (with bounded manual redirect evaluation, per-hop scope validation, credential stripping, and audit logging), or
   (b) `httpx.AsyncClient(follow_redirects=False)` with pre-flight `check_scope()` validation.
4. Internal infrastructure HTTP calls (Ollama local endpoint, LiteLLM gateway, local healthchecks) do not target pentest targets, never follow redirects, and are explicitly classified.
5. Reporting context builder (`services/reporting_engine/context_builder.py`) makes ZERO HTTP requests (compiles reports 100% offline from database ORM entities).
