=== V6 ARCHITECTURAL ANALYSIS (NI-03 CLASSIFICATION) ===
  - Nuclei templates can declare 'redirects: true'. Passing '-dr' (-disable-redirects)
    in NucleiRunner.build_argv() completely disables template-level redirects.
  - ffuf by default NEVER follows HTTP redirects; FfufRunner strips -r to prevent following.
  - Both tools with Pentesa CLI hardening achieve ZERO canary hits (0 hits).
  - However, because CLI flags rely on subprocess/tool cooperation, complete architectural
    defense-in-depth requires a dedicated Layer-2 container proxy (reassigned to Phase 9).
  - In the interim, NI-03 is mitigated via fail-closed lab-only guardrail and -dr CLI enforcement.
